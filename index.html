TikTok Integration

Extending SocialHub with TikTok analytics using Login Kit and Display API.

How We Use TikTok API

SocialHub integrates TikTok's Login Kit and Display API to provide analytics for our company's TikTok Business Account. All data is used exclusively for internal business analytics.

Requested Scopes

  • user.info.basic — Account profile and avatar
  • user.info.stats — Follower count and statistics
  • video.list — Published video list with metrics

Data Usage

  • Display follower trends on dashboard
  • Track video performance (views, likes, shares)
  • Calculate engagement scores for content analysis
  • No data is shared with third parties

Integration Flow

1
Login Kit — OAuth 2.0User authorizes SocialHub via TikTok's OAuth flow with PKCE
2
Token ExchangeAuth code exchanged for access_token (24h) and refresh_token (1 year)
3
Fetch User InfoRetrieve profile data and follower statistics via Display API
4
Fetch Video ListGet published videos with view count, likes, comments, shares
5
Display AnalyticsRender TikTok data in SocialHub dashboard alongside other platforms
